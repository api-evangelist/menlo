# Menlo Security

> Menlo Security is a cybersecurity company that secures the enterprise browser, treating the browser as the point of control for protecting both human users and AI agents. Its cloud-native Secure Enterprise Browser and Menlo Cloud Security Platform apply remote browser isolation to stop zero-day phishing, ransomware, and malware before they reach the endpoint. Menlo does not publish a public developer API or OpenAPI surface; this profile is an API Evangelist network company record.

## Products
- Secure Enterprise Browser — cloud-native browser with remote browser isolation
- AI Agent Security — governance and protection for browser-based AI agents
- AI Adaptive DLP — data loss prevention
- File Security — threat prevention for downloads and uploads
- Remote Access — zero-trust access to private applications
- Threat Prevention — zero-day phishing and ransomware protection
